# ✅ To-Do List App

A simple and responsive **To-Do List App** built using HTML, CSS, and JavaScript. It helps users organize their daily tasks and keep track of completed and pending activities.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Tasks remain saved even after refreshing the page
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📂 Project Structure

```text
To-Do-List/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and managing your daily tasks!
